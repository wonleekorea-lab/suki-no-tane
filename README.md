# 好きの種（MVP）

歩いているときにふっと浮かぶ「やってみたい」を、考える前に声に出して投げ込む箱。
溜まった種を、習慣か予定のどちらかへ送って減らしていく。

画面は横に3面だけ。**左＝記録／中央＝投げる／右＝箱**。

| 面 | やること |
|---|---|
| 中央（既定） | 丸を押す → キーボードの🎤で喋る（または打つ）→ 直して `keep` |
| 右 | 溜まった種が泡になって浮かぶ。押すと中身、**円を回すと大きさ**、押すと送り先 |
| 左 | 何日にいくつ投げたか、いくつ箱に残っているか。いちばん下に `notes` |
| 中央を下へなぞる | 思いつかない日の、めくる層。上へなぞると丸に戻る |
| 右を上へなぞる | 天国。送り終えたものが白い空を昇っている。下へなぞると箱に戻る |

文字は極力置いていない。中央の面は丸ひとつだけで、聞き取った後にはじめて文字が出る。

丸は**最初から最後まで唯一の操作**で、どの状態でも押せる（上に覆いをかぶせない）。

## 使う

**https://wonleekorea-lab.github.io/suki-no-tane/**

### iPhone に置く（本命）

上のURLを Safari で開き、共有メニューから「ホーム画面に追加」。
`manifest.json` と `sw.js` があるので、追加後はアドレスバーのない全画面で立ち上がり、
オフラインでも起動する（Sokugan と同じ形）。

音声入力（`webkitSpeechRecognition`）は **https か localhost でしか動かない**。
`file://` で開いてもマイクは使えないので、必ず上のURLか、下の手元サーバから開くこと。

### 配信

`wonleekorea-lab/suki-no-tane` の `main` ブランチ直下を GitHub Pages がそのまま配信する。
`git push origin main` すればビルドが走り、1〜2分で反映される。

### 手元で見る

```bash
python3 -m http.server 8910 --directory "suki-no-tane"
```

`http://localhost:8910/` を開く。localhost は安全なオリジン扱いなのでマイクも動く。

## ことば

画面まわりの語は**英単語1語**に統一する。日本語は、ユーザー自身の声（種の文）と、
失敗の説明だけに残す。1語で足りないものは足りるまで言い換えるのではなく、
そもそも置かない。

| 語 | 意味 | 選んだ理由 |
|---|---|---|
| `keep` | 置く | save より、手元に残す感じ |
| `forget` | やめる・そっと消す | delete は装置の語。忘れるのは人の動き |
| `again` | 言い直す | |
| `listening` | 聞いている | 状態そのもの。丸が輪になっていることの説明 |
| `turn` | 円を回して大きさを決める | |
| `want N` | いまの大きさ | boost ではなく欲しさ |
| `risen` / `not yet` | 天国に昇った数 / まだ無い | done ではなく、昇った |
| `notes` / `note` / `add` | あとで直すためのメモ | |
| `where` | どちらへ送る | 行き先を問う一語 |
| `press` | もう一度おす | |
| `habit` / `plan` | 習慣 / 予定 | |
| `back` | 箱に戻す | |
| `soon` | まだ空の箱 | empty は無いことの語。soon はこれからの語 |
| `quiet` | まだ何も送っていない | none ではなく、静かなだけ |
| `days` `today` `held` `export` `kept` | 記録面 | |
| `undo` `copied` `forget?` `yes` | 通知 | |

置き方も統一する。小文字・字間 0.2〜0.34em・低い明度。読ませるためではなく、
添えるために置く。中央寄せの語には字間ぶんの `text-indent` を入れて、光学的な中心へ戻す。

## ファイル

| ファイル | 役割 |
|---|---|
| `core.html` | **正本**。CSS・HTML・JS の全部。触るのはここだけ |
| `build.sh` | `core.html` から `index.html` と `artifact.html` を生成する |
| `shell-head.html` / `shell-foot.html` | PWA の外殻（meta、manifest、Service Worker 登録） |
| `index.html` | 生成物。ホスティングに置くのはこれ |
| `artifact.html` | 生成物。`<html>` の外殻を持たない body 相当（Artifact 公開用） |
| `manifest.json` | ホーム画面追加時の名前・色・アイコン |
| `sw.js` | アプリシェルのオフラインキャッシュ |
| `icon-*-v2.png` | アイコン。`tools/make-icons.py` の生成物 |
| `tools/make-icons.py` | アイコン生成。図案は「声に出した瞬間」＝押す丸と広がる波紋 |
| `_demo.html` | 見た目確認用の使い捨て。偽データを差し込んだだけで、実データには触れない。消してよい |

編集したら必ず：

```bash
sh "suki-no-tane/build.sh"
```

`index.html` と `artifact.html` を直接編集しないこと（次のビルドで消える）。

## データ

- 保存先は **この端末・このブラウザの localStorage**。キーは `suki_no_tane_state_v1`
- サーバへは何も送らない。アカウントも同期もない
- **ブラウザのデータを消すと種も消える**。Safari の「履歴とWebサイトデータを消去」で消える
- 記録面の「書き出す」で、全データの JSON をクリップボードにコピーできる（今の退避手段はこれだけ）
- 保存データが壊れていた場合、消さずに `suki_no_tane_state_v1_backup_<時刻>` へ退避してから空で立ち上がる
- localStorage が使えない文脈（プライベートブラウズ、埋め込み枠の中）ではメモリ上だけで動き、一度だけその旨を表示する

データの形は `好きの種_MVP実装指示.md` の定義に合わせてある（`captures` / `habits` / `reservations`）。

## 音声

**Web Speech API は使わない。**声は iOS キーボードのマイクキー（Apple のディクテーション）から入れる。

Web Speech API をやめた理由は2つ。どちらも iOS 側が出すもので、API からは止められない。

1. アプリを起動するたびにマイクの許可を訊かれる（許可が永続しない）
2. 認識の開始と終了に音が鳴る

キーボードのディクテーションなら、許可は iOS の設定で一度きり、音も鳴らない。
同じ Apple の文字起こしなので、認識の質は変わらない。

- **音声ファイルは保存も送信もしない**。アプリが受け取るのは確定した文字だけ
- ディクテーションが通信を伴うかは iOS の設定次第（オンデバイスに切り替えられる）
- 打っても喋っても同じ欄に入る。喋れない場所ではそのまま打てばいい
- 入った文は必ず画面に出る。指で直してから `keep`

### キーボードが出ているあいだ

`visualViewport` でキーボードの高さを測り、`--kb` としてページ下の余白に入れる
（`100dvh` はキーボードに反応しないため）。そのあいだは丸を畳み、下の一行と3点も引っ込めて、
文と `keep` `forget` だけをキーボードの上に残す。

### 開き直したとき

全画面アプリは閉じても再読み込みされず、前の画面のまま戻ってくる。
20秒以上離れていたら、投げる面へ戻して待機状態から始める（書きかけの文があるときは消さない）。

## このMVPでやっていないこと

- 習慣・予定の中身（1分行動、接続先、達成記録、リマインド）。いまは「送った」という状態を持つだけ
- カレンダー連携、通知、クラウド同期、アカウント
- 種の自動分類、要約、AI による解釈
- 泡の並べ替え・検索・タグ

## アイコンを描き替えるとき

**必ずファイル名の `v` を上げること。** iOS Safari はホーム画面のアイコンを URL ごとに
長期キャッシュするので、同じファイル名のまま絵だけ変えても端末には古い絵が残り続ける。

1. `tools/make-icons.py` の `VERSION` を上げて実行
2. `shell-head.html`・`manifest.json`・`sw.js` の参照を新しい名前に揃える
3. `sw.js` の `CACHE` 名も上げる
4. `sh build.sh` → commit → push

端末側は、ホーム画面から一度削除してから追加し直す（iOS は追加時の画像を焼き付けるため、
追加済みのアイコンは後から入れ替わらない）。

## めくる層

何も浮かばない日のために、◯ の面を**上から下へなぞる**と、実在の人が実際にやっていた
探究・趣味・特技・休日の過ごし方が1枚ずつ出る。なぞるたびに次が出る。
**下から上へなぞる**と ◯ に戻る。

- 中身は `core.html` の `MUSE` 配列。1件が `{who, what, note}`
- **記録の残っている事実だけを置く。**逸話や「〜と言われている」は入れない。
  足すときも同じ基準で。人物の紹介ではなく、その人が続けていた行いを書く
- 順番は毎回シャッフルする。一巡したら組み直し、境目で同じものが続かないようにする
- 縦になぞったときだけ拾う（`|dy| > |dx| × 1.4`）。横は面の移動に残してある

日本語が語の途中で折れないよう `word-break:auto-phrase` を使っている。
対応していないブラウザは黙って無視するので、壊れはしない。

## 語の切り出し

泡に出す語は、辞書も形態素解析も使わずに決める。規則はこの4つ。

1. 漢字・カタカナ・英数の連なりを「語」とみなす
2. ひらがな1字を挟む語はつなぐ（編み物・買い物）。ただしその1字が助詞なら切る（陶芸を／海に）
3. **直後が「を」「が」の語を最優先で採る。**日本語では欲しいものがそこで示される
4. 程度や質を言うだけの語（上手・得意・普通…）は下げる。時を言う語（毎日・今朝…）は前から切り離す

3が肝で、長さで選ぶと「歌が上手になりたい」で長い「上手」が勝ってしまう。

実測（20件）:

| 言ったこと | 出る語 |
|---|---|
| 歌が上手になりたい | 歌 |
| 早起きができるようになりたい | 早起き |
| 料理が得意になりたい | 料理 |
| 編み物をやってみたい | 編み物 |
| 毎朝ちゃんと味噌汁を作りたい | 味噌汁 |
| 一人でキャンプしてみたい | キャンプ |
| 毎日走りたい | 毎日 |
| 歯医者の予約を取る | 歯医者の予約 |
| もっと上手になりたい | 上手 |

外すのは、ひらがなだけの文（「ゆっくり休みたい」→「休」）。手がかりがない。

## 惹かれの大きさ

泡の大きさは `pull`（1〜40）。**カードの円を回して自分で決める。**
昔のクリックホイールと同じで、右（時計回り）で大きく、左で小さく。

- **カードのどこを触っても回る。**円の中心まわりの角度だけを見るので、
  ふちを狙う必要はない（ボタンの上だけは素通し）
- 9°で1目盛り。**ひと回しで1から40まで**届く
- 縁の点が回って、どれだけ動かしたかが見える
- 円そのものが 56px 〜 218px まで伸縮する。中の数字は逆にかけ戻して大きさを保つ
- 箱の泡は 44px 〜 178px。文は円の外に出したので、小さくしても崩れない
- ほとんど回さずに離したときだけ扱いを分ける（7°未満）。
  円の上なら送り先を出し、背景ならカードを閉じる

**開いただけでは増えない。**以前は開くたび +1 していたが、
見ただけのものが勝手に大きくなっていくので、やめた。

## 天国

`habit` か `plan` へ送ると、円が弾けて、語がひとつ上へ抜けていく。
箱の面を**下から上へなぞる**と、そこに昇ったものが白い空を漂っている。
色は白と黒を入れ替える。上に近づくほど光に溶けて消え、また下から昇り直す。

減っていく箱と、増えていく空を対にするための面。
天国の泡を押すとカードが開き、`back` で箱に戻せる。

## notes

記録の面のいちばん下。あとで直すためのヒントを溜める枠。
`state.notes` に `{id, text, createdAt}` で入り、`export` にも含まれる。
項目を押すと消せる（確認あり）。

記録の面は**面が変わったときだけ**描き直す。毎スクロールで描き直していたので、
書きかけのメモが消えていた。
